# A4 — Texture

## 시작점과 제공 범위

A1~A3를 완료한 상태에서 `student/a4`를 구현한다. 기존 색상 집, Object/model, 카메라는 그대로 사용한다. `assets/atlas.ppm`은 256×128, 4열×2행이며 각 프레임은 64×64다. `checker.ppm`은 16×16 반복 패턴이다. 이미지 디코딩은 제공되고 OpenGL 텍스처 생성부터 구현이 필요하다.

## UV와 방향

현재 Texture loader는 PPM의 첫 행(파일의 위쪽)을 OpenGL의 v=0 행으로 업로드한다. 따라서 quad 아래 정점의 v는 1, 위 정점의 v는 0으로 한다. 프레임 번호 0~3은 atlas 첫 행, 4~7은 두 번째 행이다.

프레임 UV는 vertex buffer를 매번 다시 만드는 대신 `uUvOffset + aUv*uUvScale`로 계산한다. atlas 내부에서 LINEAR가 이웃 타일까지 섞지 않도록 경계를 반 texel 안쪽으로 넣는다. wrap/filter 비교는 atlas가 아니라 별도의 checker 전체 텍스처에 UV 0~3을 적용해서 확인한다.

## 동작 요구

- 기존 색상 집들이 그대로 보이고, 텍스처 스프라이트 3개가 서로 다른 프레임/재생 속도를 가진다.
- 카메라 이동·회전·줌이 집과 스프라이트 모두에 적용된다.
- Space로 재생/정지, N으로 정지 중 한 프레임 진행.
- F로 NEAREST/LINEAR를 전환하고 카메라 줌을 통해 차이를 확인.
- V로 checker의 REPEAT/CLAMP_TO_EDGE를 전환하고 UV 범위를 벗어난 결과를 비교.
- 다음 프레임의 집 렌더링에 texture mode가 잘못 남지 않는다.
- 프레임 진행 후 남은 시간을 버리지 않는다. dt=0.46, interval=0.15면 3프레임 진행하고 0.01초가 남는다.
