# A2 — Object Transform

## 시작점

A1을 완료한 프로젝트에서 `student/a2`를 작업한다. A1 Mesh 파일을 복사하지 않는다. A2가 A1 파일을 직접 include한다. 초기 상태는 A1을 완료했다면 집 하나가 보이고 입력/변환은 구현되지 않은 상태이다.

`Object`의 자료형과 함수 인터페이스는 제공된다. Mesh 포인터는 공유하고 각 Object가 위치·각도·크기를 갖도록 실제 인스턴스와 동작을 구현한다. `support`는 행렬 저장과 곱셈만 제공하고 T/R/S 생성은 학생이 작성한다.

행렬은 column-major이고 벡터는 열벡터다. `glProgramUniformMatrix3fv`의 transpose는 `GL_FALSE`. 회전각은 라디안이다. `glUseProgram`은 main에 제공되어 있으며 uniform을 올린 후 `drawMesh`를 호출한다.

## 동작 요구

- 1/2/3으로 조작할 집 선택.
- WASD 이동, Q/E 회전, Z/X 크기 조절. 크기는 양수 범위로 제한.
- R은 선택된 Object의 위치·각도·크기를 초기화.
- O는 TRS/RTS를 한 번씩 전환하며 콘솔에 현재 순서를 표시.
- 다른 Object를 조작해도 공유 Mesh의 버텍스 데이터는 변경하지 않는다.
- reset 직후 원점에서는 두 순서가 비슷하게 보일 수 있다. 먼저 오른쪽으로 이동한 다음 회전해서 비교한다.

## 확인할 현상

TRS에서는 도형이 자신의 로컬 원점을 기준으로 회전한 뒤 배치된다. RTS에서는 translation도 rotation의 영향을 받아 월드 원점 주변을 돌 수 있다. 화면 가장자리에서 사라지는 것은 NDC 범위를 벗어난 결과일 수 있다.

현재 A2의 월드 단위는 편의상 NDC와 같은 범위다. 창의 aspect를 제대로 반영하는 과정은 A3에서 추가한다.
