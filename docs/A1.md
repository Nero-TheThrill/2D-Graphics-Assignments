## DSA와 정점 속성 연결

DSA(Direct State Access) 함수는 설정할 객체의 ID를 인자로 받는다. 버퍼에 데이터를 올리는 일과 VAO에 데이터 읽는 방법을 기록하는 일을 구분해서 작성한다.

VAO의 연결은 다음과 같이 생각하면 된다.

```text
VBO → VAO의 binding 0 → location 0: 위치(x, y)
                      → location 1: 색상(r, g, b)
EBO → VAO의 인덱스 버퍼
```

location은 shader의 입력 번호이고, binding은 VAO 안에서 VBO를 연결하는 번호다. 위치와 색상이 같은 Vertex 배열에 들어 있으므로 서로 다른 location이 같은 binding 0을 사용한다.

아래는 위치 속성 하나를 연결하는 예시다. 버퍼와 VAO를 생성하고 VBO를 binding 0에 연결한 뒤 사용한다. 색상 속성은 위 표를 보고 직접 추가한다.

```cpp
glVertexArrayAttribFormat(mesh.vao, 0, 2, GL_FLOAT, GL_FALSE,
                          offsetof(Vertex, x));
glVertexArrayAttribBinding(mesh.vao, 0, 0);
glEnableVertexArrayAttrib(mesh.vao, 0);
```

처음부터 집 전체를 만들기보다 제공된 지붕 삼각형이 보이는지 먼저 확인한다. 그다음 벽, 문, 창문을 추가한다. 사각형 하나는 삼각형 두 개로 나누면 된다. 같은 위치라도 서로 다른 색이 필요하면 정점을 나누어 사용할 수 있다.

## 완료 기준

- 지붕·벽·문·창문이 구분되어야 한다. 크기와 색은 자유이며, 그림의 꾸밈 정도는 평가하지 않는다.
- 초기화는 한 번만 수행하고 프레임 루프에서 VAO/VBO/EBO를 다시 생성하지 않는다.
- immutable buffer의 데이터를 나중에 다시 업로드하지 않는다.
- 집 렌더링은 본인의 `drawMesh`함수를 수정하여 사용한다.
