# A1 — DSA로 Indexed House 렌더링

**관련 강의:** L2 OpenGL Intro(객체·버퍼·정점 입력), L3 OpenGL Primitives(삼각형과 인덱스).

## 목표와 시작점

`student/a1/mesh.hpp`를 수정한다. 창, 입력, shader 컴파일과 색상 shader는 제공된다. 초기 실행에서 왼쪽 위 노란 삼각형만 보여도 정상이다. 이는 실행 표시이며 학생이 완성할 집과 별개의 제공 코드다.

정점은 이미 NDC에 놓는다. 모델/카메라 행렬은 다음 과제에서 추가한다. API 호출 순서만 외우지 말고 각각 어떤 객체의 설정을 변경하는지 확인한다.

| Attribute location | 입력 | 컴포넌트 | offset | Buffer binding |
|---|---|---:|---|---:|
| 0 | position | 2 | `offsetof(Vertex,x)` | 0 |
| 1 | color | 3 | `offsetof(Vertex,r)` | 0 |

`Vertex`에는 A4에서 사용할 UV 두 float도 예약되어 있다. 현재는 0이고 enable하지 않는다. 따라서 stride를 위치+색상의 5개 float로 하드코딩하면 안 된다. `GL_FLOAT`, normalize=`GL_FALSE`를 사용한다.

## 완료 기준

- 중앙에 네 부분으로 구성된 집이 보인다.
- 초기화는 한 번만 수행하고 프레임 루프에서 VAO/VBO/EBO를 다시 생성하지 않는다.
- immutable buffer의 데이터를 나중에 다시 업로드하지 않는다.
- 집 렌더링은 본인의 `drawMesh`를 사용한다. 제공된 노란 표시를 수정해 과제를 대체하지 않는다.
