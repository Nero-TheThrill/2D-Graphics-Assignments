# A3 — World → Camera → NDC → Viewport

## 시작점

A1과 A2를 완료하고 `student/a3`를 수정한다. 이전 Mesh와 Object/model 함수를 계속 사용한다. A3의 main은 카메라 조작을 중심으로 구성되어 있고, A2의 Object 조작은 A2 실행 파일에서 계속 확인할 수 있다.

## 구현 순서

| TODO | 구현 |

| A3.1 | 카메라 pose의 역변환으로 View 구성 |

| A3.6 | shader에서 `CameraToNdc * View * Model` 적용 |
| A3.7 | framebuffer 크기로 glViewport 갱신, camera update 호출 |

Camera.height는 **보이는 세로 길이 전체**다. 기본 6, 가로 전체 길이는 `height*aspect`. 확대하면 height가 작아진다. height는 2~20 범위로 제한한다. 카메라 이동은 world X/Y축 기준으로 한다.

카메라의 world pose를 `T*R`로 생각했을 때 역변환의 순서와 부호를 직접 유도한다. Model은 물체를 world에 놓고, View는 world를 카메라 기준으로 표현한다.

## 필수 확인

- 카메라를 오른쪽으로 이동하면 장면은 화면에서 왼쪽으로 보인다.
- 카메라를 회전해도 집들의 world 위치는 변경되지 않는다.
- 줌으로 더 넓게/좁게 볼 수 있다.
- 창을 넓게/좁게 변경해도 집의 가로세로 비율이 유지된다.
- 창 최소화 시 height=0으로 나눠 오류를 만들지 않는다.
- viewport는 픽셀 영역을 설정한다. 이번 구현에서 이를 대신하는 viewport 행렬을 shader에 또 곱하지 않는다.

## 보너스 — 클릭 위치에 집 추가

`cursorToWorld`와 main의 `enableClickPlacement`를 완성한다. GLFW 커서는 창 논리 좌표·좌상단 원점이다. window 크기로 NDC를 계산한 뒤, CameraToNdc와 View의 역순을 적용한다. framebuffer aspect는 투영에 사용한 값과 같아야 한다. 회전·줌·창 크기 변경 후에도 클릭한 위치에 집이 나타나야 한다.
